ChemSearch 🧪
A fast and modular Command Line Interface (CLI) (for now) tool to extract chemical safety data, GHS hazard statements, and chemical properties directly from public databases.

> **Note:** This is my first public open-source project! I developed it to learn about modular architecture, defensive JSON parsing, and responsible API consumption.
> Any feedback, suggestions, or Pull Requests are incredibly welcome.

**INSTALLATION**

Clone the repository to your local machine:

```bash
git clone [https://github.com/OffScreens/ChemSearch.git](https://github.com/OffScreens/ChemSearch.git)
cd ChemSearch
```
**USAGE:**
Execute with
```bash
python main.py
```
Enter the name of the chemical compound you want to search!
